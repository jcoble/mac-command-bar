# Session-switch teardown recon

## Scope and evidence rule

This is a source-only map of state whose lifetime can cross a session switch. Each claim is marked `[VERIFIED]` when it is directly visible in the current source or history, and `[ASSUMED]` when it is a relative-memory or causal judgement without a heap measurement. The current `/next` page imports the shell editor at `+page.svelte:29` and renders one unkeyed `EditorPanel` at `+page.svelte:1703-1712`.

The historical remount is also verified: commit `375dab3` added `sessionKey={rail.activeOwnedId}` and a `{#key sessionKey}` around the Monaco child; commit `2e56483` reverted it. The current render has no session key (`tauri-svelte-preview/src/lib/shell/components/EditorPanel.svelte:1042-1062`; `tauri-svelte-preview/src/routes/next/+page.svelte:1703-1712`).

## 1. State that survives or grows across a switch

### Editor and workspace state

- **[VERIFIED] Monaco editor and models:** the long-lived Monaco child owns one editor instance, `ownedModels`, an in-flight target-model map, a 24-entry external-target LRU, tab-model paths, saved tab text, and CodeLens/symbol caches (`tauri-svelte-preview/src/lib/MonacoSourceEditor.svelte:326-394`, `:418-454`). `applyPreview` creates or reuses a model and adds it to `ownedModels`; every opened tab is touched in the tab LRU (`tauri-svelte-preview/src/lib/MonacoSourceEditor.svelte:1889-1935`).

- **[VERIFIED] Monaco's explicit model disposals are not switch disposals:** `disposeTabModel` and `disposeAllTabModels` exist, including force disposal of the tab-model LRU (`tauri-svelte-preview/src/lib/MonacoSourceEditor.svelte:1391-1406`). They are called by individual close and close-all actions only (`tauri-svelte-preview/src/lib/shell/components/EditorPanel.svelte:822-847`), not by `selectOwned` (`tauri-svelte-preview/src/routes/next/+page.svelte:887-930`).

- **[VERIFIED] Monaco's full teardown exists only in `onDestroy`:** it disposes editor/provider/listener resources, the editor, all `ownedModels`, and clears the model and CodeLens caches (`tauri-svelte-preview/src/lib/MonacoSourceEditor.svelte:2950-3030`). Because the current `CodeEditor` has no key and is rendered from the shell parking stage, this path is page/component teardown rather than a session-switch path (`tauri-svelte-preview/src/lib/shell/components/EditorPanel.svelte:1042-1062`; `tauri-svelte-preview/src/lib/shell/components/ShellFrame.svelte:172-186`).

- **[VERIFIED] The editor store is one shared live strip:** `editorState` keeps `openFiles`, `activePath`, `projectRoot`, and symbols (`tauri-svelte-preview/src/lib/shell/editor/editorStore.svelte.ts:35-52`). `restoreEditorFiles` and `resetEditorState` replace that state, but do not dispose Monaco models (`tauri-svelte-preview/src/lib/shell/editor/editorStore.svelte.ts:167-178`).

- **[VERIFIED] Open-file entries can duplicate file text in JavaScript state:** the open-file shape includes `preview`, `draftContent`, loading/error state, and target information (`tauri-svelte-preview/src/lib/shell/editor/editorStoreOps.ts:18-43`). `EditorPanel` also retains per-path diagnostics/read-only state, read-in-flight paths, warmed project roots, mode-restore promises, and language-server status (`tauri-svelte-preview/src/lib/shell/components/EditorPanel.svelte:145-171`, `:185-186`). Its panel cleanup clears timers/listeners but does not clear those maps or dispose `codeEditor` (`tauri-svelte-preview/src/lib/shell/components/EditorPanel.svelte:924-956`).

- **[VERIFIED] The page deliberately retains full tab entries for up to three sessions:** `snapshotWorkspace` copies the live open-file entries into `retainedTabs` before writing the small persisted workspace record (`tauri-svelte-preview/src/routes/next/+page.svelte:790-812`). `RetainedTab.preview` is the file contents, and the cap is three sessions; the source explicitly says a held session keeps full text for every open file (`tauri-svelte-preview/src/lib/shell/sessionWorkspaces.ts:407-436`, `:484-496`). The persisted record separately keeps up to twelve paths per session, plus active/selected path, scroll, diff, conversation UI, browser, and center-layout state (`tauri-svelte-preview/src/lib/shell/sessionWorkspaces.ts:65-106`; `tauri-svelte-preview/src/routes/next/+page.svelte:799-812`).

- **[VERIFIED] The session rail itself is shared bookkeeping, not a teardown store:** `rail` holds the owned/available session lists and active id; removing a session removes it from the rail, while `setAvailable` deliberately strips `latestTurns` to avoid retaining full history in the rail (`tauri-svelte-preview/src/lib/shell/stores/sessionRailStore.svelte.ts:11-23`, `:47-71`). Selecting another session changes the active id but does not clear prior conversation/workspace payloads (`tauri-svelte-preview/src/lib/shell/stores/sessionRailStore.svelte.ts:52-65`; `tauri-svelte-preview/src/routes/next/+page.svelte:887-930`).

### Terminal and conversation state

- **[VERIFIED] Hidden terminal views remain mounted:** `TerminalSurface` renders a host for every `ownedId` and keeps the hosts for the life of the page (`tauri-svelte-preview/src/lib/shell/components/TerminalSurface.svelte:1-18`, `:131-148`). `liveConversationTerminals` keeps a view record and a session-to-view map; `showView` hides other views but does not dispose them (`tauri-svelte-preview/src/lib/liveConversationTerminals.ts:55-72`, `:100-115`, `:170-202`).

- **[VERIFIED] Each xterm view carries a large scrollback buffer:** the factory sets `scrollback: 20000` and documents an approximate 20 MB per view at 120 columns, including hidden views (`tauri-svelte-preview/src/lib/shell/xtermFactory.ts:160-166`). A view is freed only through `closeView`/`closeOwned` or page-wide disposal, where the terminal and addons are disposed (`tauri-svelte-preview/src/lib/liveConversationTerminals.ts:255-305`; `tauri-svelte-preview/src/lib/shell/terminalService.ts:813-878`). `selectOwned` calls `service.show`, which only changes visibility (`tauri-svelte-preview/src/routes/next/+page.svelte:916`; `tauri-svelte-preview/src/lib/liveConversationTerminals.ts:175-202`).

- **[VERIFIED] Conversation sessions are retained by owned id:** `conversationSessions` is a record of full `ConversationWorkspaceState` objects, including timelines, agent items, plans/tasks, children, attachments, sent attachments, capabilities, pending requests, and recent events (`tauri-svelte-preview/src/lib/shell/conversation/conversationStore.svelte.ts:80-137`, `:147-151`). A snapshot rebuild publishes a complete state for that session, and older transcript pages prepend timeline/items (`tauri-svelte-preview/src/lib/shell/conversation/conversationStore.svelte.ts:596-717`, `:732-770`). Recent events are capped, but the main timeline/item collections are not capped in this code (`tauri-svelte-preview/src/lib/shell/conversation/conversationStore.svelte.ts:709-716`; `:732-770`).

- **[VERIFIED] Conversation session records are not deleted on switch:** `removeConversationSession` deletes one record only when the session is removed (`tauri-svelte-preview/src/lib/shell/conversation/conversationStore.svelte.ts:1412-1435`; `tauri-svelte-preview/src/routes/next/+page.svelte:1407-1426`). `selectOwned` loads or changes the selected session but does not remove the previous one (`tauri-svelte-preview/src/routes/next/+page.svelte:931-948`).

- **[VERIFIED] Conversation service maps have session/attachment lifetime:** the service keeps resyncing, ensuring, and terminal-projection maps, plus attachment hydration maps (`tauri-svelte-preview/src/lib/shell/conversation/conversationService.ts:60-85`, `:318-335`, `:406-430`). Resync/ensure promises are removed when their requests settle, but terminal projections are removed only for the selected previous session or full service teardown (`tauri-svelte-preview/src/lib/shell/conversation/conversationService.ts:326-330`, `:441-455`, `:596-625`; `tauri-svelte-preview/src/routes/next/+page.svelte:911`).

- **[VERIFIED] Draft persistence retains per-session maps:** the debounce, write queue, and revision maps are keyed by `ownedId`; pending timers are cleared by flush, completed writes are removed, but the revision map remains per id (`tauri-svelte-preview/src/lib/shell/conversation/conversationDraftPersistence.ts:12-17`, `:31-81`).

- **[VERIFIED] Presence history is also keyed by session:** `sessionPresenceHistory` is a module-level map and is removed only by explicit `clearSessionPresence`/session removal, not by selecting another session (`tauri-svelte-preview/src/lib/shell/conversation/sessionPresence.ts:45-58`, `:216-238`; `tauri-svelte-preview/src/lib/shell/conversation/conversationStore.svelte.ts:1433-1435`).

### Browser state

- **[VERIFIED] Browser state is a module singleton rather than one workspace per session:** the browser store creates one `workspace` and one backend (`tauri-svelte-preview/src/lib/shell/browser/browserStore.svelte.ts:66-104`). The workspace contains `ownedId`, tabs, tab order, active tab, feedback queue, pending selection/markup, and markup captures (`tauri-svelte-preview/src/lib/shell/browser/browserTypes.ts:162-183`).

- **[VERIFIED] Browser tabs and captures persist until explicitly closed/consumed:** `createBrowserTab` adds tabs to the workspace and creates the native tab; `closeBrowserTab` is the path that closes and removes one (`tauri-svelte-preview/src/lib/shell/browser/browserModel.ts:317-376`, `:396-414`). Deactivation hides the workspace and clears only interaction/pending selection state, not the tab collection (`tauri-svelte-preview/src/lib/shell/browser/browserModel.ts:305-315`).

- **[VERIFIED] Browser session snapshots are retained in a module map keyed by `ownedId`:** reads/writes clone entries in `snapshots` (`tauri-svelte-preview/src/lib/shell/browser/browserSessionSnapshots.ts:27-62`). `restoreBrowserState` navigates or closes only the current active tab when the incoming snapshot requires it; it does not dispose the whole browser workspace (`tauri-svelte-preview/src/lib/shell/browser/browserStore.svelte.ts:152-184`).

- **[VERIFIED] BrowserPanel has per-session visual/capture state:** annotations, strokes, captures, blobs, tool/expanded state, and related interaction state are held in the mounted component (`tauri-svelte-preview/src/lib/shell/panels/browser/BrowserPanel.svelte:103-149`). Its owned-id effect writes the old panel snapshot and restores the new one; `restorePanelSnapshot` revokes only the old blob URL, while the workspace tabs remain (`tauri-svelte-preview/src/lib/shell/panels/browser/BrowserPanel.svelte:367-411`, `:720-735`).

- **[VERIFIED] All eight right-column panels stay mounted for the whole session:** RightPanel renders Agents, Browser, Files, History, Run, Session Context, Source Control, and Worktrees simultaneously; the active tab only changes display (`tauri-svelte-preview/src/lib/shell/components/RightPanel.svelte:3-15`, `:45-69`). - **[VERIFIED] History retains loaded records and checkout rows while visible:** it holds `loadedRecords`, load outcome, project loading state, expanded/collapse state, and checkout rows (`tauri-svelte-preview/src/lib/shell/panels/history/HistoryPanel.svelte:89-128`). Search and the hidden-panel effect clear the arrays; project toggles may release only the selected keys while a load is being replaced (`tauri-svelte-preview/src/lib/shell/panels/history/HistoryPanel.svelte:130-158`, `:160-209`). It destructures only `visible`, so `root` and `ownedId` do not drive a session-switch reset (`tauri-svelte-preview/src/lib/shell/panels/history/HistoryPanel.svelte:80-91`). Its service holds records in a module-level `Map` until `release` (`tauri-svelte-preview/src/lib/shell/sessionLibrary/sessionLibraryService.ts:111-139`).

Commit files retain `expanded`, `byCommit`, and selected/repository state; the service retains in-flight top/file/diff request bookkeeping (`tauri-svelte-preview/src/lib/shell/git/gitCommitFilesStore.svelte.ts:54-106`; `tauri-svelte-preview/src/lib/shell/git/gitCommitFilesService.ts:100-149`, `:168-218`). - **[VERIFIED] The main Git panel resets its root-scoped store on activation, but this is replacement rather than full component teardown:** `gitService.activate` resets `gitPanelState` and reloads for the new root (`tauri-svelte-preview/src/lib/shell/git/gitService.ts:471-481`). If the selected diff is cleared, the conditional native diff child unmounts and disposes its editor/models (`tauri-svelte-preview/src/lib/shell/components/GitDiffView.svelte:99-128`; `tauri-svelte-preview/src/lib/shell/components/git/NativeGitDiffEditor.svelte:140-147`).

Its watcher is stopped on visibility/root changes, but those local state objects are not cleared by the watcher cleanup (`tauri-svelte-preview/src/lib/shell/panels/files/FilesPanel.svelte:130-185`). The explorer service does reset/re-scan root-scoped records on a root change (`tauri-svelte-preview/src/lib/shell/explorer/explorerService.ts:127-133`; `tauri-svelte-preview/src/lib/shell/explorer/explorerStore.svelte.ts:87-121`).

## 2. `restoreWorkspace` replay order and reactive work

### Switch wrapper order

**[VERIFIED]** The exact switch sequence is in `selectOwned` (`tauri-svelte-preview/src/routes/next/+page.svelte:887-950`):

1. **[VERIFIED]** It clears the draft flag, captures `previous` and `switching`, clears the rail error, and calls `setActiveOwned(ownedId)` (`tauri-svelte-preview/src/routes/next/+page.svelte:887-901`). The active-id change reaches the already-mounted surfaces before the explicit replay call.
2. **[VERIFIED]** For a real switch, it flushes the previous session's draft and snapshots that session's editor/tree/diff/conversation/browser/layout state (`tauri-svelte-preview/src/routes/next/+page.svelte:902-910`; `:790-812`).
3. **[VERIFIED]** It stops the previous conversation terminal projection, updates the extension-probe workspace for the selected session, and calls `service.show(ownedId)` (`tauri-svelte-preview/src/routes/next/+page.svelte:911-916`). `service.show` changes terminal visibility; it does not dispose the hidden view (`tauri-svelte-preview/src/lib/liveConversationTerminals.ts:175-202`).
4. **[VERIFIED]** It calls `shellPanels.sessionPicked()` before workspace replay (`tauri-svelte-preview/src/routes/next/+page.svelte:917-920`). That re-points explorer, Git, worktrees, stacks, Problems, editor, and browser activation according to the current selection (`tauri-svelte-preview/src/lib/shell/panelActivation.ts:197-204`, `:231-246`; `tauri-svelte-preview/src/lib/shell/shellPanels.ts:122-140`).
5. **[VERIFIED]** Only then, in the switching branch, it calls `restoreWorkspace(ownedId)` and `restoreTabsFor(ownedId)` (`tauri-svelte-preview/src/routes/next/+page.svelte:921-930`).
6. **[VERIFIED]** After the workspace replay, it ensures the selected conversation session, sets raw/structured mode, and loads the selected session's conversation and draft on a switch (`tauri-svelte-preview/src/routes/next/+page.svelte:931-948`).

### `restoreWorkspace` order

**[VERIFIED]** Inside `restoreWorkspace`, the replay is synchronous up to the asynchronous work initiated by panel/editor services, and the order is (`tauri-svelte-preview/src/routes/next/+page.svelte:837-885`):

1. **[VERIFIED]** Abort when session loads are gated; otherwise restore the selected session's browser snapshot (`tauri-svelte-preview/src/routes/next/+page.svelte:837-842`).
2. **[VERIFIED]** Read the newly selected root, resolve that session's remembered diff, then either clear Git selection or request the stored diff (`tauri-svelte-preview/src/routes/next/+page.svelte:843-855`).
3. **[VERIFIED]** Restore conversation UI fields and, for app-origin sessions, force structured mode (`tauri-svelte-preview/src/routes/next/+page.svelte:856-863`; `tauri-svelte-preview/src/lib/shell/conversation/conversationStore.svelte.ts:1412-1430`).
4. **[VERIFIED]** Restore the center Dockview layout if one was saved (`tauri-svelte-preview/src/routes/next/+page.svelte:864`; `tauri-svelte-preview/src/lib/shell/layout/centerDock.ts:329-340`).
5. **[VERIFIED]** Take this session's retained full tab entries, remove them from the retained queue, and compute the restore plan (`tauri-svelte-preview/src/routes/next/+page.svelte:865-867`; `tauri-svelte-preview/src/lib/shell/sessionWorkspaces.ts:506-519`, `:548-563`).
6. **[VERIFIED]** Replace the shared editor store with this session's retained tabs, or reset it to empty when there are none (`tauri-svelte-preview/src/routes/next/+page.svelte:868-873`; `tauri-svelte-preview/src/lib/shell/editor/editorStore.svelte.ts:167-178`).
7. **[VERIFIED]** Set `restoringWorkspace`, request every not-retained path in strip order, request the remembered active path last, then clear the guard in `finally` (`tauri-svelte-preview/src/routes/next/+page.svelte:875-881`).
8. **[VERIFIED]** If a stored record exists, restore the explorer selection and scroll offset last (`tauri-svelte-preview/src/routes/next/+page.svelte:882-885`).
9. **[VERIFIED]** `restoreTabsFor` then applies the remembered center tab and right tab. The center-tab application can announce Git History and the right-tab application can announce Source Control, Worktrees, Stacks, or Browser (`tauri-svelte-preview/src/routes/next/+page.svelte:329-387`).

### Effects and re-entrancy hazards

- **[VERIFIED]** The `setActiveOwned` call precedes the old-workspace snapshot and therefore invalidates props/effects in mounted surfaces before `restoreWorkspace` starts (`tauri-svelte-preview/src/routes/next/+page.svelte:887-910`). BrowserPanel writes/restores per-session panel snapshots on `ownedId` changes (`tauri-svelte-preview/src/lib/shell/panels/browser/BrowserPanel.svelte:720-735`); Context, Files, Source Control, Worktrees, Run, Agents, and Conversation surfaces likewise receive the new root/id while remaining mounted (`tauri-svelte-preview/src/lib/shell/components/RightPanel.svelte:45-69`; `tauri-svelte-preview/src/lib/shell/panels/context/SessionContextPanel.svelte:78-112`; `tauri-svelte-preview/src/lib/shell/panels/agents/AgentsPanel.svelte:41-76`).

- **[VERIFIED]** `shellPanels.sessionPicked` can reset/reload root-scoped services before the editor replay: explorer re-scans on a root change, Git resets/reloads, and the gated panels are re-pointed (`tauri-svelte-preview/src/lib/shell/explorer/explorerService.ts:127-133`; `tauri-svelte-preview/src/lib/shell/git/gitService.ts:471-481`; `tauri-svelte-preview/src/lib/shell/panelActivation.ts:197-246`).

- **[VERIFIED]** `restoreBrowserState`, `restoreConversationWorkspace`, center-layout restore, and tab restore all mutate reactive state in sequence (`tauri-svelte-preview/src/routes/next/+page.svelte:842-885`). Editor-store mutation is observed by EditorPanel's intelligence effect and lazy-editor effect (`tauri-svelte-preview/src/lib/shell/components/EditorPanel.svelte:692-701`, `:901-903`); each requested file can then cause a Monaco `applyPreview` effect that creates/attaches a model (`tauri-svelte-preview/src/lib/MonacoSourceEditor.svelte:2923-2935`, `:1889-1935`).

- **[VERIFIED]** The `restoringWorkspace` flag prevents each replayed `requestOpenFile` from selecting the editor tab in the page callback (`tauri-svelte-preview/src/routes/next/+page.svelte:875-881`; `:1707-1712`).
