Selective adapter installation

One signed provider feed can keep publishing versions for all three providers. Each machine downloads only the adapter its user chooses. The backend release contains the server alone.

Current path

The provider feed is signed, but updates.rs requires all three adapters and installs every file in one bundle. remoteBackendPackage.ts includes every adapter in the 423 MB backend archive. Settings offers a single Install adapters button.

Boundaries

Use the existing provider registry, updater, signed manifest, backend installer, and Settings control. The provider-native session remains the context authority; no transcript migration or new service. An unavailable provider gives a visible install path and never silently changes identity. Keep active work and failed verification from replacing the last usable installed set.
