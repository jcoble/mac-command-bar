Browse folders on the remote machine

Both remote path fields keep direct typing and gain a Browse button. Opening the chooser authenticates through the existing SSH setup, then lists just the current directory.

Remote working directory on agent-workbox

Typing a path and pressing Enter opens it. A folder row opens that folder; Choose this folder copies the verified path into the original field. Cancel leaves the field unchanged.

No deployment, recursive scans, idle SSH process, polling, or looping animation. Each listing returns at most 500 folders and ends within 15 seconds. This is a static visual preview; folder names above illustrate the interaction.
