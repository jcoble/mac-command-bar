## Current Highest Priority Bug

### Monaco Reference Peek Opens Same-File Refs But Not Cross-File Refs

User observed:

- Monaco reference peek opens.
- Same-file reference selection navigates correctly.
- Cross-file reference selection does not switch/open the target file.
- The native/Rust/index reference list can navigate cross-file, but the user prefers the Monaco peek UI.

Diagnosis:

- Custom Monaco providers return `Location`s using `monaco.Uri.file(target.path)`.
- Monaco can list those external locations, but the editor only has a model for the currently selected file.
- The app has no bridge that maps Monaco's external file URI navigation back into the app's tab/open-file system.

The fix should keep Monaco's UI and let the app own file switching.

### Recommended Implementation

In `MonacoSourceEditor.svelte`:

1. Add helpers:

```ts
function sourcePathFromMonacoUri(uri: Monaco.Uri | null | undefined) {
  if (!uri) return "";
  return uri.fsPath || decodeURIComponent(uri.path || "");
}

function locationFromMonacoSelection(
  selection: Monaco.IRange | Monaco.IPosition | null | undefined
) {
  const value = selection as Partial<Monaco.IRange & Monaco.IPosition> | null | undefined;
  const line = value?.startLineNumber ?? value?.lineNumber ?? 1;
  const column = value?.startColumn ?? value?.column ?? 1;
  return { line: Math.max(1, line), column: Math.max(1, column) };
}
```

2. Add model preloading for external targets:

```ts
async function ensureSourceTargetModel(monaco: typeof Monaco, target: SourceRecord) {
  const uri = monaco.Uri.file(target.path);
  const existing = monaco.editor.getModel(uri);
  if (existing) return existing;

  const externalPreview = await onExternalPreviewLookup?.(target);
  if (!externalPreview) return null;

  const model = monaco.editor.createModel(
    externalPreview.content,
    monacoLanguageForSource(externalPreview.language),
    uri
  );
  ownedModels.add(model);
  return model;
}

async function ensureSourceTargetModels(monaco: typeof Monaco, targets: SourceRecord[]) {
  await Promise.all(targets.map((target) => ensureSourceTargetModel(monaco, target).catch(() => null)));
}
```

Do not create fake excerpt-only models. Monaco peek line numbers need real file content.

3. In all cross-file providers, preload models before returning mapped locations:

- `registerSourceDefinitionProvider`
- `registerSourceReferenceProvider`
- `registerSourceImplementationProvider`
- `registerSourceTypeDefinitionProvider`

Pattern:

```ts
const targets = await onReferenceLookup?.(request);
await ensureSourceTargetModels(monaco, targets ?? []);
return (targets ?? []).map((target) => sourceReferenceTargetToLocation(monaco, target));
```

4. Intercept Monaco external navigation:

```ts
function installExternalCodeEditorNavigation() {
  if (!editor || originalOpenCodeEditor) return;
  const service = (editor as unknown as { _codeEditorService?: typeof patchedCodeEditorService })._codeEditorService;
  if (!service?.openCodeEditor) return;

  patchedCodeEditorService = service;
  originalOpenCodeEditor = service.openCodeEditor.bind(service);
  service.openCodeEditor = async (input, source, sideBySide) => {
    const path = sourcePathFromMonacoUri(input?.resource);
    if (path && path !== currentPath && onExternalNavigation) {
      const location = locationFromMonacoSelection(input.options?.selection);
      await onExternalNavigation({ path, ...location });
      return editor;
    }

    return originalOpenCodeEditor?.(input, source, sideBySide) ?? null;
  };
}
```

Call it after `editor = monaco.editor.create(...)`.

5. Restore the patch on destroy:

```ts
if (patchedCodeEditorService && originalOpenCodeEditor) {
  patchedCodeEditorService.openCodeEditor = originalOpenCodeEditor;
}
patchedCodeEditorService = null;
originalOpenCodeEditor = null;
modelChangeDisposable?.dispose();
```
