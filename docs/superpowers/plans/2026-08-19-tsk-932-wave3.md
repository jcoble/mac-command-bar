> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the wave-3 batch for Assembly — the bug lanes, the context meter, the plan chip, the styling pass on its own branch, the helper model, agy as a provider, and (after the memory measurement) the Editor/Supercharged switch with tree-sitter as the only highlighter.

- KISS/YAGNI: smallest diff that passes the named test; no new abstraction, flag, shim, fallback or drive-by refactor unless the task names it; a diff ~2× the budget or a file the task does not name means stop and report.
- One way only: when a task replaces a mechanism, the old one is deleted in the same task.
- Browser checks: `playwright-cli -s=<task-name> open <url>` (never `--headed`), `resize 1710 990`, `eval "() => window.innerWidth + 'x' + window.innerHeight"` must print `"1710x990"`, screenshots looked at, then `close` and verify the process tree is gone; report `Browser cleanup: stopped <session>`.
- Builds: one `cargo`/`pnpm` build per lane at a time; `MSBUILDDISABLENODEREUSE=1` where .NET is involved (not here). Sub-agents never commit unless the task says so; the controller commits.
- Stop-don't-fabricate: a required command that fails → stop and report the exact error verbatim. A wrong guess at a path during exploration is not a blocker.
- Routing: anything the owner sees → Opus 5 (or Fable); high-judgment implementation, QA, every review → SOL medium (`-m gpt-5.6-sol -c 'model_reasoning_effort="medium"'`); recon, audits, tightly specified implementation → Luna Max (`-m gpt-5.6-luna -c 'model_reasoning_effort="max"'`). Lanes that clone/install need `-c 'sandbox_workspace_write.network_access=true'`.
- Test commands (verbatim, from `tauri-svelte-preview/`): Rust `cargo test --manifest-path src-tauri/Cargo.toml <test_name>`; frontend `node --experimental-strip-types scripts/<name>.test.ts`; type check `pnpm exec svelte-check --threshold error 2>&1 | tail -1` (baseline 16 errors / 6 files — must not rise); Rust warnings `pnpm check:rust`.
