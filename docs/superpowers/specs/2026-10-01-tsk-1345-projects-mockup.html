Mockup Project menu: one row per folder per machine; the cloud marks agent-workbox. Heading is 16px per DESIGN.md (T3 uses about 26px; owner can override). Badges are plain grey; coloured badges possible if wanted. New project, step 1: choose the machine. "Add remote machine…" and "Manage remote machines…" move here from the old machine menu. Step 2: browse folders on that machine; Add (⌘ Enter) adds the folder in the path field. "Open in Finder" shows only for This Mac, so it is absent here. A folder inside git's own data is refused in plain words, and Add stays off until the path changes. The machine label is read-only (the project decides it) and shows only for workbox projects. New worktree is created on the first message, from the branch on the right, under ~/dev/work/worktrees/<repo>/<branch>. In Current checkout, picking a branch runs git checkout. A branch already checked out in another worktree points this session at that worktree instead. In New worktree, the pick is the base branch. Sidebar grouped by project across machines (the default). The centred empty draft uses the composer's open shape (message line above its controls), as in T3.
