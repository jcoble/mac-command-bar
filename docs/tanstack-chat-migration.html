Highlighting

The existing syntax highlighter remains in use. The provided TanStack example uses TextPart from React, Vue or Solid; the installed Svelte UI package does not provide that component. Its framework-independent highlighter can feed Assembly's Svelte spans, but currently lacks Rust and C# grammars among other supported Assembly languages. No second highlighter or plain-text regression was introduced. The owner was offered the tradeoff; no replacement decision has been received.

Pipeline structured output

TanStack supports progressive and completed structured-output parts. Assembly already validates eight pipeline receipt shapes in Rust after a turn finishes. Showing typed partial receipts would require the backend to emit structured-output events and share the schema contract; this migration does not invent a frontend-only schema or claim that integration is complete.

Streaming structured output · Harness output schemas · Implementation boundary: src-tauri/src/workflow.rs.

Local and remote sandboxes

TanStack sandboxes provision and resume the environment running an agent harness. Assembly already owns local processes, SSH placement, provider-native sessions, ordered journals, approvals and cancellation. A custom sandbox provider could map Assembly's owner ID into that contract, but one system must own create, resume, cancel and destroy. This is a separate backend integration, not an additional runtime inside this chat migration.
