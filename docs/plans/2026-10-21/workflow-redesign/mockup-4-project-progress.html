How this project runs

  • The project run ended at your approval; the orchestrator then created the 17 slice tasks.
  • It starts each slice as a normal task run, one at a time, in plan order.
  • It starts the next slice only when GitHub reports the previous PR merged.
  • Each slice has its own Notion task, so its PR closes only that task.
  • A slice that stops goes to the orchestrator; scope questions and protected-path taps come to you (expect them on about 10–12 of the 17 slices); the orchestrator merges.
