No project directory is required here. Closing Settings keeps an established connection; cancelling an in-progress attempt stops that attempt.

Five completion checks

  1. First Send immediately shows the existing activity spinner at the pending user message. It disappears on completion, cancellation or failure.
  2. Settings has saved Connect and Disconnect. Reconnect restores remote conversations without creating a chat. SQLite preserves profiles through app restart.
  3. The access choice represents actual sandbox permissions and persists through resume, reconnect and switching. Approval prompting is not mistaken for write permission.
  4. After connection, a new chat chooses its remote folder. Existing chats restore their own folder; Files and Git operate on that machine.
  5. Model, effort and access are available upon session selection without sending a message.
