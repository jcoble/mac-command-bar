## What Changed This Session

### Center Runtime Tabs

Files:

- `tauri-svelte-preview/src/lib/sourceDockLayout.ts`
- `tauri-svelte-preview/src/lib/sourceDockviewWorkspace.ts`
- `tauri-svelte-preview/src/routes/+page.svelte`

Terminal and Browser were moved from the old bottom dock into the center Dockview group:

- `terminal` and `browser` now default to `center` in `sourceDockLayout.ts`.
- `normalizeSourceDockLayout(...)` migrates terminal/browser out of `bottom` and appends them to `center`.
- `moveSourceDockPanel(...)` redirects attempts to move terminal/browser to `bottom` back to `center`.
- `sourceLayoutVersion` is now `2026-06-center-runtime-no-bottom-row`.
- `dockPanelMoveTargets(...)` returns only `['center']` for terminal/browser.
- `runtimeDockPanelRendered()` now returns false.
- The visible old bottom runtime shell was removed from the route template.
- Terminal/browser DOM is staged in `.source-runtime-panel-stage` so Dockview can attach the panels.

### Saved Center Dockview Layout Disabled

File: `tauri-svelte-preview/src/lib/sourceDockviewWorkspace.ts`

Added `restoreStoredLayout?: boolean` to `SourceDockviewWorkspaceOptions`.

File: `tauri-svelte-preview/src/routes/+page.svelte`

`initializeSourceDockviewCenter(...)` now uses:

```ts
storedLayout: null,
restoreStoredLayout: false,
```

Why: Dockview had saved a previous center layout where terminal/browser were effectively short/below-editor. Panel IDs still matched, so `fromJSON(...)` kept reviving the bad geometry. The new center stack should be rebuilt from `sourceDockLayout` instead.

### Terminal Full-Height CSS Fix

File: `tauri-svelte-preview/src/routes/+page.svelte`

The user inspected DevTools and found this rule was causing the terminal to not use the full panel height:

```css
:global(.source-dockview-center-shell .source-dockview-attached-panel.terminal-launchpad) {
  grid-template-rows: auto minmax(0, 1fr) auto minmax(0, 96px);
}
```

That rule was removed. The terminal should now fall back to the normal `.terminal-launchpad` grid:

```css
grid-template-rows: auto minmax(0, 1fr);
```

This was the latest user-visible fix before the handoff. It should be visually rechecked after a refresh/reload.
